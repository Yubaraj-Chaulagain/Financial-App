# Financial CRM Android APK Project

This is a native Android WebView project for the Financial CRM web application.

App URL:
https://fulkumari.com.np/sheettoweb/App/Fanancial%20App/Crm

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install the generated APK on Android.

The phone needs internet access because this version loads the live CRM website.
